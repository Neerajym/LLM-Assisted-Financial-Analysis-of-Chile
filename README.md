### How to Run the Notebook

1. Open the `LLM_Chile_IMF_.ipynb` file in Google Colab.
2. Add your Gemini API key under `GEMINI_API_KEY` in Colab Secrets and enable notebook access.
3. If the notebook asks for the IMF report, upload the Chile IMF Country Report No. 24/41 PDF.
4. Run the cells in order, starting from the top.
5. Once the code finishes running, the results, analysis and dashboard will be displayed in the notebook.

**Note:** The API key is stored privately in Colab Secrets and is not included in this repository.
